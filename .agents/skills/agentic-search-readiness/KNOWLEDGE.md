# Agentic search readiness

Use `SKILL.md` to run the checks. Read this reference to plan distribution, verify crawler access and measure AI visibility.

## 1. Preserve the SEO foundation

Indexing, canonical signals, accessible content and page experience remain the foundation. Do not defer a confirmed technical or on-page defect to pursue a speculative AI-search opportunity. Make useful answers available in the initial HTML and keep structured data consistent with visible content.

## 2. Distribution and measurement

### 2.1 Search outcomes

Track impressions, visits and useful actions separately. An impression does not establish a visit or a conversion. Interpret changes using the project's actual data and comparable periods.

### 2.2 Market scope

Use the declared audience, language and market. Do not transfer adoption figures, traffic patterns or regulatory requirements between markets without project-specific evidence.

### 2.3 Off-domain presence

Choose relevant community, reference, video or professional surfaces based on the audience and observed citations. Keep entity names and descriptions consistent. Participate through useful answers, demonstrable work and accurate profiles. NEVER: fabricate mentions, buy fake endorsements or create deceptive accounts.

No fixed list of domains or citation-share benchmark applies to every project. Verify the surfaces relevant to the target queries before proposing a channel.

### 2.4 Sustainable participation

Choose channels the project can maintain. Define a useful contribution, responsible contributor and measurement approach before expanding distribution.

### 2.5 AI share of voice

Measure the share of sampled answers that mention or cite the brand over a fixed prompt set and engine list. Record prompts, dates, engine configuration, geography where available and observed answers. Repeat under comparable conditions and describe sample limits. Keep this measure separate from rankings, referral traffic, conversions and the impressions available in the Search Console Generative AI performance report. Check the actual report or an authorized export. Do not assume a connected Search Analytics API provides the same dataset.

### 2.6 Answer-first content

Start relevant sections with a self-contained answer, then provide explanation and evidence. Avoid arbitrary character budgets and excessive fragmentation. Do not promise a numerical visibility lift from a formatting change.

## 3. Machine access

### 3.1 Structured data and interfaces

Keep JSON-LD, feeds and sitemaps accurate and current. Add a conversational or agent endpoint only for a demonstrated project need, with supported tooling and an explicit maintenance plan.

### 3.2 Effective crawler policy

Review `robots.txt` together with server, CDN and firewall controls. Distinguish search crawling, training and user-requested retrieval. Test the effective response for the intended crawler and page. A declared preference does not establish actual access. For Google AI Search, also inspect the effective Search generative AI control and parent-property inheritance in Search Console without changing the account. Keep search access available where the project intends indexing. Use enforced access controls where retrieval must be blocked.

### 3.3 Transactions

Agent checkout and payment interfaces apply only when the project sells an eligible product and authorizes that work. Verify the current integration, user authorization and actual transaction behavior before making a recommendation. Mark irrelevant capabilities N/A.

### 3.4 Agent navigation

Use available project tooling to inspect accessibility structure, layout stability, content availability and machine-readable summaries. Report unavailable checks as unmeasured.

## 4. Limits

### 4.1 Market-specific requirements

Hosting licences, regional infrastructure and platform-specific transaction channels require an applicable project need. Do not present them as universal SEO or GEO requirements.

### 4.2 llms.txt

A served file must remain valid and current for its intended consumers. Google explicitly says Search ignores `llms.txt` for visibility and rankings. Do not prioritize it over indexing, useful content or crawler access.

### 4.3 Content length

Choose answer length for the question and reader. A fixed character count is not an AI-visibility requirement.

## 5. Workplan

1. Resolve confirmed technical and on-page blockers.
2. Improve answer clarity, accurate structured data and crawler access.
3. Compare sustainable distribution opportunities against the project's goals.
4. Establish a reproducible prompt sample and measure actual outcomes.
5. Revisit interfaces or transactions only when justified by the project's needs.
